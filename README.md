# Waffle Studio menu

Single-page menu app with −/+ ordering on WhatsApp, events, A4 menu PDF and QR poster.

- Customer menu: `https://<username>.github.io/<repo>/`
- Owner editor: add `#admin` to the link. Enter GitHub username, repo, branch and a fine-grained token with Contents: read & write on this repo, then tap Publish.
- Menu data lives in `menu.json`, photos in `images/`.

Enable hosting: repo Settings → Pages → Deploy from branch → `main` / root.
